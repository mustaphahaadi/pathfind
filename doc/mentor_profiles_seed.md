# Mock Mentor Profiles — Initial Seed Dataset

**AmaliTech Capstone · Product Family 2**

---

## Purpose

This document contains the initial set of fictional mentor profiles prepared for seeding and testing the Pathfind mentorship platform. The profiles support realistic demonstrations of mentor search, filtering, profile viewing, and structured mentorship requests.

- **Coverage:** Software Engineering, Data, Product Management, UX/UI Design, and Cloud/DevOps.
- **Data status:** Fictional demo/development data. No profile represents a real mentor.
